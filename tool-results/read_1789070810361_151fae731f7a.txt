     1→"""Risk Guardian — the global Risk Decision Engine.
     2→
     3→Architecture position (user-pinned):
     4→
     5→    exchange truth
     6→          |
     7→    reconciliation            (what actually happened?)
     8→          |
     9→    actual state
    10→          |
    11→    RISK GUARDIAN             <- THIS MODULE (is the state still allowed?)
    12→          |
    13→    RiskDecision
    14→          |
    15→    engine execution          (what do we do? — engine's OWN bounded machinery)
    16→          |
    17→    audit / fold              (what was actually executed?)
    18→
    19→Design rules (user-pinned, v1 — fully deterministic):
    20→- No AI, no heuristics, no "maybe": every verdict is a pure function of the
    21→  measured ACTUAL state and the RiskLimits.
    22→- ALL TEN limits are evaluated on EVERY pass and journaled with the decision
    23→  (G2 completeness) — a green decision is provably a checked decision.
    24→- Rule priority is EXPLICIT (the ladder below). The verdict is the FIRST fired
    25→  rule in ladder order; a lower-priority ALLOW can never override a
    26→  higher-priority FLATTEN/ESCALATE (G1 dominance — structural, then tested).
    27→- The guardian NEVER trades. It produces RiskDecision records; the engine
    28→  executes a permitted FLATTEN via its own validated unwind path (G4:
    29→  every risk_ transition must be preceded by a FLATTEN decision).
    30→- Purity / idempotency: evaluate() twice on the same world -> the identical
    31→  decision and ZERO new journal events (dedupe by content signature). Restart
    32→  re-evaluates instead of reconstructing: same world -> same decision ->
    33→  zero duplicate events (G3/G6).
    34→
    35→The ladder (rank order — the user's explicit priority):
    36→
    37→    rank  rule                        verdict    escalates   fires when
    38→    ----  --------------------------  --------   ---------   -------------------------
    39→      0   EXTERNAL_REDUCTION          ESCALATE   yes         recon classified external
    40→                                                        reduction (latches until recon
    41→                                                        reclassifies HEALTHY — same
    42→                                                        semantics as invariant R4)
    43→      0   RECON_CONFLICT              ESCALATE   yes         recon decided ESCALATE_CONFLICT
    44→                                                        (strict drift, frozen policy,
    45→                                                        orphan conflict)
    46→      1   VENUE_UNAVAILABLE           BLOCK      if long    any endpoint (positions/
    47→                                                        trades/account) down; escalates
    48→                                                        once the outage exceeds
    49→                                                        max_venue_unavailable_ticks
    50→      2   SINGLE_LEG                  FLATTEN    yes         unhedged notional above
    51→                                                        max_single_leg_exposure_usd,
    52→                                                        OUTSIDE the bounded entry
    53→                                                        window (see below)
    54→      3   LIQUIDATION_CRITICAL        FLATTEN    yes         distance-to-liquidation below
    55→                                                        the minimum (positions open)
    56→      4   MAX_DAILY_LOSS              FLATTEN    yes         daily loss budget consumed
    57→      4   MAX_DRAWDOWN                FLATTEN    yes         drawdown budget consumed
    58→      5   STALE_DATA                  BLOCK      no          positions view older than
    59→                                                        max_stale_data_ticks
    60→      5   LIMIT_BREACH                BLOCK      no          max_position / max_total_
    61→                                                        exposure / max_leverage exceeded
    62→      5   REPAIR_BUDGET_EXHAUSTED     BLOCK      yes         pair unresolved and repair
    63→                                                        attempts >= emergency budget
    64→      -   (no rule fired)             ALLOW      no          everything healthy
    65→
    66→Composition decisions (documented, not accidental):
    67→- EXTERNAL_REDUCTION / CONFLICT escalates rather than flattens because the
    68→  protective flatten is ALREADY issued by reconciliation + engine composition
    69→  before the guardian evaluates; the guardian's added value is fail-closed:
    70→  no auto-trading against an unknown actor until recon proves HEALTHY.
    71→- VENUE_UNAVAILABLE (BLOCK) outranks SINGLE_LEG / LIQUIDATION (FLATTEN):
    72→  while blind we do not add risk anywhere; the moment observation heals, the
    73→  higher-severity measurement rules fire on the (last-known) truth. This is
    74→  the user's explicit ladder order.
    75→- STALE_DATA sits BELOW the FLATTEN-class rules: a risk-off on last-known
    76→  venue truth is always safe (closing positions cannot worsen risk), while
    77→  ledger mutations legitimately refuse stale data (reconciliation R5). New
    78→  exposure is still blocked on stale data.
    79→- SINGLE_LEG measures PERSISTENT unhedged exposure: while the pair is inside
    80→  the bounded entry/confirm window (PAIR_PENDING / LEG_A_FILLED /
    81→  LEG_B_FILLED) the engine's own timeout machinery bounds the transient
    82→  exposure; from LEG_B_PARTIAL / REPAIR / HEDGED / EMERGENCY_UNWIND (and for
    83→  orphan exposure with no pair at all) the guardian measures it. Deterministic
    84→  state-based gating, not a heuristic.
    85→- BLOCK gates NEW exposure only. In-flight pair resolution is already
    86→  committed risk, handled by the engine's bounded machinery; FLATTEN is the
    87→  guardian's tool when that machinery is not enough.
    88→- FLATTEN execution composition rule (consumed by the engine wrapper): the
    89→  engine executes a guardian FLATTEN by sizing unwind orders against the
    90→  LEDGER, so it may act only once reconciliation has established truth
    91→  (`flatten_execution_permitted`): classification HEALTHY / DUPLICATE_TRADE /
    92→  LATE_FILL, or an acted SYNC decision. While reconciliation is still
    93→  RECONFIRMing, RETRYing (stale/blind) or holding a conflict, the verdict
    94→  STANDS (journaled, escalated where flagged) and executes the moment truth
    95→  is established — one bounded tick of deferral, never a blind mutation.
    96→  This mirrors the reconciliation module's own no-blind-action discipline.
    97→
    98→Boundary semantics (pinned per limit kind, tested at exactly-threshold and
    99→+/- one smallest step):
   100→- capacity limits breach strictly ABOVE   (position, exposure, leverage,
   101→  single-leg, stale age, outage duration)
   102→- budget limits breach AT the limit       (daily loss, drawdown, repair budget
   103→  — the budget is consumed when it is reached)
   104→- margin limits breach strictly BELOW     (liquidation distance)
   105→"""

   194→def _num(s: str) -> Optional[Decimal]:
   195→    try:
   196→        return dec(s)
   197→    except Exception:  # noqa: BLE001 — "n/a" / "inf" / "unset" are not numeric
   198→        return None

   201→def breached_for(limit: str, measured: str, limit_value: str) -> Optional[bool]:
   202→    """Recompute the breach flag from journaled strings. Returns None when the
   203→    recorded values do not allow a definitive recomputation ("n/a", "unset",
   204→    "inf", or limits whose breach depends on state gating)."""
   205→    if limit == "venue_unavailable":
   206→        out = _num(measured)
   207→        return True if (out is not None and out > 0) else None
   208→    if limit == "min_liquidation_distance_pct":
   209→        m, lv = _num(measured), _num(limit_value)
   210→        if m is None or lv is None:
   211→            return None
   212→        return m < lv
   213→    m, lv = _num(measured), _num(limit_value)
   214→    if m is None or lv is None:
   215→        return None
   216→    if limit in _CAPACITY_LIMITS:
   217→        return m > lv
   218→    if limit in _BUDGET_LIMITS:
   219→        if limit == "emergency_repair_budget":
   220→            # state-gated (pair unresolved): at/above budget is NOT definitively
   221→            # breached (a resolved pair keeps its historical attempt count);
   222→            # below budget is definitively NOT breached.
   223→            return False if m < lv else None
   224→        return m >= lv
   225→    return None

   228→# --------------------------------------------------------------------------
   229→# The measured ACTUAL state (pure input to the decision)
   230→# --------------------------------------------------------------------------
   231→@dataclass(frozen=True)
   232→class RiskState:
   233→    """Everything the guardian knows, measured AFTER reconciliation ran —
   234→    the honest 'actual state' picture. Immutable, side-effect-free."""
   235→    tick: int
   236→    view: tuple                       # ((leg, signed qty), ...) venue positions view
   237→    view_tick: int                    # -1 when the positions endpoint is down
   238→    positions_available: bool
   239→    trades_available: bool
   240→    account_available: bool
   241→    equity: Optional[Decimal]         # None when the account endpoint is down
   242→    realized_pnl_day: Optional[Decimal]
   243→    peak_equity: Optional[Decimal]
   244→    min_liq_distance_pct: Optional[Decimal]   # None when flat / account down
   245→    outage_ticks: tuple               # ((endpoint, ticks), ...) while down
   246→    pair_live: bool
   247→    pair_state: Optional[str]         # None when no pair exists
   248→    pair_unresolved: bool
   249→    repair_attempts: int
   250→    recon_classification: Optional[str]
   251→    recon_decision: Optional[str]
   252→    px_long: Decimal
   253→    px_short: Decimal
   254→
   255→    # ----- derived measurements (all deterministic) -----
   256→    @property
   257→    def any_endpoint_down(self) -> bool:
   258→        return not (self.positions_available and self.trades_available
   259→                    and self.account_available)
   260→
   261→    @property
   262→    def max_outage_ticks(self) -> int:
   263→        return max((n for _name, n in self.outage_ticks), default=0)
   264→
   265→    @property
   266→    def qty(self) -> dict:
   267→        return dict(self.view)
   268→
   269→    @property
   270→    def gross_notional(self) -> Decimal:
   271→        q = self.qty
   272→        return (abs(q.get("L1", ZERO)) * self.px_long
   273→                + abs(q.get("L2", ZERO)) * self.px_short)
   274→
   275→    @property
   276→    def unhedged_notional(self) -> Decimal:
   277→        """Net quantity valued at the reference (long-leg) mark."""
   278→        q = self.qty
   279→        net = q.get("L1", ZERO) + q.get("L2", ZERO)
   280→        return abs(net) * self.px_long
   281→
   282→    @property
   283→    def max_abs_leg_qty(self) -> Decimal:
   284→        q = self.qty
   285→        return max(abs(q.get("L1", ZERO)), abs(q.get("L2", ZERO)))
   286→
   287→    @property
   288→    def in_entry_window(self) -> bool:
   289→        return self.pair_state in (s.value for s in ENTRY_WINDOW_STATES)
   290→
   291→    @property
   292→    def day_loss(self) -> Optional[Decimal]:
   293→        if self.realized_pnl_day is None:
   294→            return None
   295→        return max(ZERO, -self.realized_pnl_day)
   296→
   297→    @property
   298→    def drawdown_pct(self) -> Optional[Decimal]:
   299→        if self.peak_equity is None or self.equity is None:
   300→            return None
   301→        if self.peak_equity <= ZERO:
   302→            return Decimal(100)      # degenerate world: fail-safe full drawdown
   303→        return (self.peak_equity - self.equity) / self.peak_equity * Decimal(100)
   304→
   305→    @property
   306→    def leverage(self) -> Optional[str]:
   307→        """Gross notional / equity. equity <= 0 -> unbounded ('inf')."""
   308→        if self.equity is None:
   309→            return None
   310→        if self.equity <= ZERO:
   311→            return "inf"
   312→        return str(self.gross_notional / self.equity)

   328→def decide(state: RiskState, limits: RiskLimits) -> RiskDecision:
   329→    """Pure: no I/O, no mutation, no clock. Same (state, limits) -> the same
   330→    decision, byte for byte (ts is carried in from the state)."""
   331→    # ---- measurement snapshots (None = unmeasurable) ----
   332→    unhedged = state.unhedged_notional
   333→    pos_qty = state.max_abs_leg_qty
   334→    gross = state.gross_notional
   335→    lev = state.leverage
   336→    loss = state.day_loss
   337→    dd = state.drawdown_pct
   338→    liq = state.min_liq_distance_pct
   339→    stale_age = (state.tick - state.view_tick) if state.positions_available else None
   340→    outage = state.max_outage_ticks
   341→    budget_left = limits.emergency_repair_budget
   342→
   343→    # ---- per-limit breach flags (pinned boundary semantics) ----
   344→    b_single = (limits.max_single_leg_exposure_usd is not None
   345→                and not state.in_entry_window
   346→                and unhedged > limits.max_single_leg_exposure_usd)
   347→    b_position = (limits.max_position_qty is not None
   348→                  and pos_qty > limits.max_position_qty)
   349→    b_exposure = (limits.max_total_exposure_usd is not None
   350→                  and gross > limits.max_total_exposure_usd)
   351→    b_leverage = (limits.max_leverage is not None and (
   352→        lev == "inf" or (lev is not None and dec(lev) > limits.max_leverage)))
   353→    b_daily = (limits.max_daily_loss_usd is not None and loss is not None
   354→               and loss >= limits.max_daily_loss_usd)
   355→    b_dd = (limits.max_drawdown_pct is not None and dd is not None
   356→            and dd >= limits.max_drawdown_pct)
   357→    b_liq = (limits.min_liquidation_distance_pct is not None and liq is not None
   358→             and liq < limits.min_liquidation_distance_pct)
   359→    b_stale = (limits.max_stale_data_ticks is not None and stale_age is not None
   360→               and stale_age > limits.max_stale_data_ticks)
   361→    b_venue = state.any_endpoint_down
   362→    b_budget = (budget_left is not None and state.pair_unresolved
   363→                and state.repair_attempts >= budget_left)
   364→
   365→    evaluations = (
   366→        _eval("max_single_leg_exposure_usd", "SINGLE_LEG",
   367→              str(unhedged) if not state.in_entry_window else f"{unhedged} (entry-window)",
   368→              _lv(limits.max_single_leg_exposure_usd), b_single),
   369→        _eval("max_position_qty", "LIMIT_BREACH", str(pos_qty),
   370→              _lv(limits.max_position_qty), b_position),
   371→        _eval("max_total_exposure_usd", "LIMIT_BREACH", str(gross),
   372→              _lv(limits.max_total_exposure_usd), b_exposure),
   373→        _eval("max_leverage", "LIMIT_BREACH", NA if lev is None else lev,
   374→              _lv(limits.max_leverage), b_leverage),
   375→        _eval("max_daily_loss_usd", "MAX_DAILY_LOSS",
   376→              NA if loss is None else str(loss),
   377→              _lv(limits.max_daily_loss_usd), b_daily),
   378→        _eval("max_drawdown_pct", "MAX_DRAWDOWN",
   379→              NA if dd is None else str(dd),
   380→              _lv(limits.max_drawdown_pct), b_dd),
   381→        _eval("min_liquidation_distance_pct", "LIQUIDATION_CRITICAL",
   382→              NA if liq is None else str(liq),
   383→              _lv(limits.min_liquidation_distance_pct), b_liq),
   384→        _eval("max_stale_data_ticks", "STALE_DATA",
   385→              NA if stale_age is None else str(stale_age),
   386→              _lv(limits.max_stale_data_ticks), b_stale),
   387→        _eval("venue_unavailable", "VENUE_UNAVAILABLE",
   388→              str(outage) if b_venue else "0",
   389→              _lv(limits.max_venue_unavailable_ticks), b_venue),
   390→        _eval("emergency_repair_budget", "REPAIR_BUDGET_EXHAUSTED",
   391→              str(state.repair_attempts),
   392→              _lv(budget_left), b_budget),
   393→    )
   394→
   395→    # ---- rule firing (ladder order == RISK_RULES order) ----
   396→    fired = []
   397→    if state.recon_classification == Classification.EXTERNAL_REDUCTION.value:
   398→        fired.append("EXTERNAL_REDUCTION")
   399→    if state.recon_decision == Decision.ESCALATE_CONFLICT.value:
   400→        fired.append("RECON_CONFLICT")
   401→    if b_venue:
   402→        fired.append("VENUE_UNAVAILABLE")
   403→    if b_single:
   404→        fired.append("SINGLE_LEG")
   405→    if b_liq:
   406→        fired.append("LIQUIDATION_CRITICAL")
   407→    if b_daily:
   408→        fired.append("MAX_DAILY_LOSS")
   409→    if b_dd:
   410→        fired.append("MAX_DRAWDOWN")
   411→    if b_stale:
   412→        fired.append("STALE_DATA")
   413→    if b_position or b_exposure or b_leverage:
   414→        fired.append("LIMIT_BREACH")
   415→    if b_budget:
   416→        fired.append("REPAIR_BUDGET_EXHAUSTED")
   417→
   418→    winner = RULE_INDEX[fired[0]] if fired else None
   419→    verdict = winner.verdict if winner else RiskVerdict.ALLOW
   420→    decided_by = winner.name if winner else "NONE"
   421→    escalate = any(RULE_INDEX[n].escalate for n in fired)
   422→    if "VENUE_UNAVAILABLE" in fired and limits.max_venue_unavailable_ticks is not None \
   423→            and outage > limits.max_venue_unavailable_ticks:
   424→        escalate = True
   425→
   426→    if winner is None:
   427→        reason = "all ten limits evaluated, none breached"
   428→    else:
   429→        detail = []
   430→        if "LIMIT_BREACH" in fired:
   431→            hit = [n for n, b in (("max_position_qty", b_position),
   432→                                  ("max_total_exposure_usd", b_exposure),
   433→                                  ("max_leverage", b_leverage)) if b]
   434→            detail.append("limits over: " + ",".join(hit))
   435→        if "VENUE_UNAVAILABLE" in fired:
   436→            down = [n for n, _t in state.outage_ticks]
   437→            detail.append("endpoints down: " + ",".join(down))
   438→        reason = winner.description + (" (" + "; ".join(detail) + ")" if detail else "")
   439→
   440→    signature = "|".join((
   441→        verdict.value, decided_by, str(escalate), ",".join(fired),
   442→        ";".join(f"{e.limit}={e.measured}/{e.limit_value}:{int(e.breached)}"
   443→                 for e in evaluations),
   444→    ))
   445→
   446→    return RiskDecision(
   447→        ts=state.tick, verdict=verdict, decided_by=decided_by, escalate=escalate,
   448→        triggered_by=tuple(fired), subject=SUBJECT, reason=reason,
   449→        evaluations=evaluations, signature=signature,
   450→    )

   453→# --------------------------------------------------------------------------
   454→# The guardian: measure (venue + fold + last recon) -> decide -> journal

   456→def last_risk_decision(events: list) -> Optional[dict]:

   458→        if ev.get("t") == "risk_decision":
   459→            return ev
   460→    return None

   468→def flatten_execution_permitted(recon_classification: Optional[str],
   469→                                recon_decision: Optional[str]) -> bool:
   470→    """The engine may size a guardian FLATTEN against the ledger only after
   471→    reconciliation established truth (no unexplained/unknown state)."""
   472→    return (recon_classification in FLATTEN_EXECUTION_TRUTH_OK_CLASS
   473→            or recon_decision in FLATTEN_EXECUTION_TRUTH_OK_DECISION)
   474→
   475→
   476→class RiskGuardian:
   477→    """Produces RiskDecision records over the reconciled actual state.
   478→
   479→    The guardian appends ONLY `risk_decision` audit events (deduped by
   480→    content signature — a standing decision is not re-journaled). It never
   481→    places orders, never mutates the ledger, never touches the exchange."""
   482→
   483→    def __init__(self, journal: Journal, exchange: FakeExchange, spec: PairSpec,
   484→                 limits: RiskLimits, policy: Policy = None):
   485→        self.j = journal
   486→        self.ex = exchange
   487→        self.spec = spec
   488→        self.limits = limits
   489→        self.policy = policy
   490→
   491→    # ------------------------------------------------------------------ api
   492→    def measure(self) -> RiskState:
   493→        st = fold(self.j.events)
   494→
   495→        positions_available, view, view_tick = True, None, -1
   496→        try:
   497→            v, vt = self.ex.get_positions_snapshot()
   498→            view, view_tick = tuple(v.items()), vt
   499→        except ApiUnavailable:
   500→            positions_available = False
   501→            # last-known positions: the (post-reconciliation) ledger
   502→            view = tuple(st.ledger.items())
   503→            view_tick = -1
   504→
   505→        trades_available = self.ex.endpoint_available("trades")
   506→        account_available = True
   507→        equity = realized = peak = liq = None
   508→        try:
   509→            acct = self.ex.get_account()
   510→            equity, realized, peak = acct.equity, acct.realized_pnl_day, acct.peak_equity
   511→            liq = acct.min_liq_distance_pct
   512→        except ApiUnavailable:
   513→            account_available = False
   514→
   515→        outage = tuple((name, self.ex.endpoint_outage_ticks(name))
   516→                       for name in ("positions", "trades", "account")
   517→                       if not self.ex.endpoint_available(name))
   518→
   519→        pair_live = bool(st.orders) and st.state != S.UNWOUND and st.phase != PHASE_DONE
   520→        pair_state = st.state.value if st.orders else None
   521→        unresolved = pair_live and st.state in UNRESOLVED_STATES
   522→
   523→        recon = last_recon_result(self.j.events)
   524→        classification = recon.get("classification") if recon else None
   525→        recon_decision = recon.get("decision") if recon else None
   526→
   527→        return RiskState(
   528→            tick=self.ex.now, view=view, view_tick=view_tick,
   529→            positions_available=positions_available,
   530→            trades_available=trades_available,
   531→            account_available=account_available,
   532→            equity=equity, realized_pnl_day=realized, peak_equity=peak,
   533→            min_liq_distance_pct=liq, outage_ticks=outage,
   534→            pair_live=pair_live, pair_state=pair_state, pair_unresolved=unresolved,
   535→            repair_attempts=st.repair_attempts,
   536→            recon_classification=classification, recon_decision=recon_decision,
   537→            px_long=self.spec.px_long, px_short=self.spec.px_short,
   538→        )
   539→
   540→    def evaluate(self) -> RiskDecision:
   541→        """One full pass: measure -> decide -> journal (deduped). Pure with
   542→        respect to the world: the only effect is at most one audit event."""
   543→        state = self.measure()
   544→        decision = decide(state, self.limits)
   545→        last = last_risk_decision(self.j.events)
   546→        if last is None or last.get("signature") != decision.signature:
   547→            self.j.append(decision.to_event())
   548→        return decision
   549→
